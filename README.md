# Кибер Башня: Космический Автошутер (Cyber Tower) | VK Play Edition

Научно-фантастический авто-шутер и рогалик (One-Button / Bullet Heaven Roguelite), адаптированный для публикации на платформе **VK Play** и **VK Mini Apps**.

## Особенности игры
- **Процедурная графика и звук**: 100% процедурная отрисовка на HTML5 Canvas 2D, синтез SFX и саундтрека на лету через Web Audio API (ноль внешних тяжелых ассетов).
- **Интеграция с VK Play & VK Bridge**:
  - Поддержка нативного `iframeApi` (`mailru.core.js`) и `VK Bridge`.
  - Межстраничная реклама (Interstitial) с кулдауном 60 сек и защитой от показа во время активного боя.
  - Реклама за вознаграждение (Rewarded Video): воскрешение башни (60% HP), удвоение чипов, реролл карт прокачки.
  - Автоматическое глушение звука и пауза игры при показе рекламы, сворачивании вкладки (`visibilitychange`) и потере фокуса (`blur`).
  - Сохранение прогресса в `localStorage` и облако.
  - Таблица лидеров и поддержка 3 языков: Русский (RU), Английский (EN), Турецкий (TR).
- **Мета-прогрессия**: мастерская постоянных улучшений, кибер-импланты, дроны-питомцы (Рекс, Сокол, Скарабей), скины и колесо фортуны.

## Сборка проекта
Для сборки бандла и обновления релизных файлов:
```bash
node build_vkplay.js
```

Скрипт объединяет модули из `src/` в `game.bundle.js` и генерирует единый автономный `index.html`.
